# Data Quality Rules

## UK Land Registry Dataset

### Price

Rules:

- Must not be null
- Must be greater than 0

### Postcode

Rules:

- Must not be null

### Transaction Date

Rules:

- Must not be null
- Must be a valid date

### Property Type

Rules:

Allowed Values:

- D (Detached)
- S (Semi-Detached)
- T (Terraced)
- F (Flat/Maisonette)
- O (Other)

### Tenure

Allowed Values:

- F (Freehold)
- L (Leasehold)
