## Project Status

## Overview

The UK Housing Intelligence Platform is an end-to-end data engineering,
analytics, and machine learning platform for analysing UK housing markets.

The project integrates:

- Data Engineering
- Data Processing
- Analytics
- AWS Data Lake
- Snowflake Data Warehouse
- dbt
- Apache Airflow
- Machine Learning
- FastAPI
- Streamlit
