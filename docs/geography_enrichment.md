# Geography Enrichment

## Purpose

The Geography Enrichment layer enhances the Housing Intelligence dataset with administrative geography and spatial coordinates.

## Added Attributes

### Administrative Geography

- Local Authority
- Region
- Country

### Spatial Geography

- Latitude
- Longitude

## Data Sources

### ONS Postcode Directory (February 2026)

Used for:

- LSOA → Local Authority mapping
- LSOA → Region mapping
- LSOA → Country mapping
- LSOA centroid coordinates

### ONS Geography Lookup Tables

Used for:

- Local Authority names
- Region names
- Country names

## Result

All Housing Intelligence datasets now support:

- Regional analysis
- Geographic drill-down
- Interactive mapping
- Location intelligence
