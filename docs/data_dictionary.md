# Data Dictionary

## price

Description:
Property sale price in GBP.

Data Type:
Integer

Example:
655000

---

## postcode

Description:
UK postcode of the property.

Data Type:
String

Example:
SK8 4JU

---

## property_type

Description:
Type of residential property.

Values:

- D = Detached
- S = Semi-detached
- T = Terraced
- F = Flat/Maisonette
- O = Other

---

## tenure_type

Description:
Ownership type.

Values:

- F = Freehold
- L = Leasehold
